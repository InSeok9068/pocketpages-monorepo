# AI 오디오북

| 위치                            | 누가                       | 무엇을                                      |
| ------------------------------- | -------------------------- | ------------------------------------------- |
| 책 상세                         | `users.admin_manager = true` | AI 오디오북 생성 요청·일시 정지·진행률 확인 |
| 리더 → 읽어주기 → AI 오디오북   | 서재에 책이 있는 사용자    | 생성된 음성만 재생. 리더는 생성하지 않음    |
| 리더 → 읽어주기 → 로컬 오디오북 | 모두                       | 기기 음성(Web Speech)으로 재생              |

`admin_manager`는 hidden 필드라 사용자가 API로 직접 바꿀 수 없고, 어드민에서만 설정합니다.
생성된 구간이 하나도 없으면 리더의 AI 오디오북 항목은 비활성화되고 로컬 오디오북이 기본으로 선택됩니다.

## 서버 설정

먼저 `pb_schema.json`의 `book_audio_chunks`, `book_audio_progress`, `book_audio_jobs`, `users.admin_manager`를 관리자에서 import합니다.

서비스 `.env`의 `GEMINI_APIKEY`를 그대로 사용할 수 있습니다.
`GEMINI_API_KEY`, `GEMINI_AI_KEY`도 지원하며 키는 브라우저에 전달하지 않습니다.
책 상세에서 모델을 선택합니다. 기본은 `gemini-3.8-flash-lite-tts`이며 Lite가 사용 중이면 비어 있는 `gemini-3.8-flash-tts`가 선택됩니다.
모델마다 미완료 작업은 한 책만 등록할 수 있습니다. 대기·생성 중·일시 정지·실패 작업이 있으면 해당 책 이름과 함께 선택을 막고, 완료하거나 삭제하면 풀립니다. 예약 시 서버 트랜잭션에서도 다시 확인합니다.
이는 미완료 작업에 따른 제한이며 Gemini의 실제 일일 잔여 요청 수를 조회하는 기능은 아닙니다. 앞선 책이 완료돼도 일일 한도가 소진됐다면 다음 작업은 429 대기 규칙을 따릅니다.

모델·목소리·말투·본문 처리 버전은 최초 작업에 고정하고 설정 해시로 묶습니다. 다시 시작·재생·청취 기록은 저장된 작업의 설정을 사용합니다. 모델을 바꾸려면 오디오북을 삭제한 뒤 다시 요청합니다. `BOOKLOG_TTS_MODEL` 환경변수는 사용하지 않습니다.
생성할 때 본문이 Google에 전달되며, 무료 티어에서는 제품 개선에 사용될 수 있습니다.

## 본문 정리

| 규칙                 | 기준                                                                                                                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 판권 페이지 제외     | 파일 이름(`copyright`, `colophon`, `imprint` 등), `epub:type="copyright-page·colophon·imprint"`, 또는 2,500자 이하 챕터에 ISBN과 판권 용어(발행인, 출판등록, 1판 1쇄, © 등)가 2개 이상 |
| 띄어 쓴 영문 붙이기  | 영문 한 글자와 가운뎃점(ㆍ · •)이 번갈아 나오면 붙임: `Pㆍrㆍoㆍlㆍoㆍgㆍuㆍe` → `Prologue`. 한글 사이 가운뎃점은 유지                                                                 |
| 줄 앞 장식 기호 제거 | 줄 맨 앞의 □ ■ ◇ ◆ ○ ● ▶ ☐ ✓ 등. 문장 중간 기호는 유지                                                                                                                                 |

표지·저자 소개는 오디오북 도입부로 남깁니다. 규칙이 바뀌면 영향받는 구간만 본문 해시가 달라져 다시 생성됩니다.

## 생성

| 단계        | 동작                                                                                                                                                                                                                                                                                                                                                                             |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 요청        | `book_audio_jobs`에 설정만 고정하고 바로 응답합니다. `total_chunks = 0`은 구간 등록 대기 표시입니다.                                                                                                                                                                                                                                                                             |
| 구간 등록   | 다음 cron 실행이 EPUB 전체를 최대 3,000자 구간(문단·문장 경계, 음성 약 7분)으로 나눠 `queued`로 등록합니다. 이 실행은 생성하지 않습니다. 출력 한도 16,384토큰(초당 25토큰, 약 10분 55초) 안에서 하루 요청 수를 줄이기 위한 길이입니다.                                                                                                                                           |
| 생성        | `booklog-audio-book` cron이 2분마다 한 구간을 만듭니다. 책의 처음부터 순서대로 생성합니다.                                                                                                                                                                                                                                                                                       |
| 429         | 해당 구간은 시도 횟수를 늘리지 않고, 작업 전체를 30분 쉽니다.                                                                                                                                                                                                                                                                                                                    |
| 정책 차단   | `400 Request blocked … policy`. 그 구간만 10분 뒤로 미루고, 작업은 쉬지 않고 다음 구간을 생성합니다. 같은 본문으로 2회 차단되면 가운데에 가까운 문단·문장 경계에서 조각 2개로 나눕니다(원래 구간은 `split`, 조각은 `split_path` 0·1). 조각도 2회 차단되면 다시 나누고(00·01…), 300자 미만은 더 나누지 않고 5회까지 재시도합니다(3,000자 구간은 약 190자까지 나뉨). 조각은 다음 구간보다 먼저 생성합니다.                                                                                                                                                                                                                 |
| 기타 실패   | 구간별 최대 5회(10분 × 시도 횟수 간격)까지 재시도하고, 작업은 10분 쉽니다. 실패 사유는 구간 `error_message`와 로그에 남습니다.                                                                                                                                                                                                                                                   |
| 일시 정지   | 진행 중인 한 구간은 마저 저장하고, 이후 구간은 만들지 않습니다.                                                                                                                                                                                                                                                                                                                  |
| 다시 시작   | 실패 구간·조각의 시도 횟수를 초기화하고, 현재 본문과 맞지 않는 옛 구간과 그 조각을 정리합니다.                                                                                                                                                                                                                                                                                                  |
| 구간 재생성 | 어드민에서 `book_audio_chunks.regenerate_requested`를 true로 바꾸면, 다음 실행에서 그 구간의 음성 파일·시도 횟수·재시도 시각·오류를 지우고 `queued`로 되돌립니다. 나뉜 구간이면 조각도 지우고 원래 구간부터 다시 만듭니다. 끝난 작업은 다시 진행 상태가 됩니다. 같은 모델에 다른 책의 미완료 작업이 있으면 해제될 때까지 기다립니다. 생성 중인 구간은 끝난 뒤 처리합니다. 완성된 구간이 이상하게 들릴 때(누락, 음색) 다시 만들 때 씁니다. |

- 책 상세의 **오디오북 삭제**는 그 EPUB의 모든 낭독 설정 음성 파일·구간·작업·청취 기록을 지웁니다. EPUB 원본은 남습니다. 생성 중이던 구간은 결과를 저장하지 않고 버립니다.
- 생성 소유권은 DB 트랜잭션으로 확보하므로 cron 실행이 겹쳐도 같은 구간을 두 번 만들지 않습니다. Gemini 요청 제한 시간은 300초, 생성 소유권 유효 시간은 10분입니다. 소유권 유효 시간이 생성 시간보다 짧으면 진행 중인 구간을 중단으로 보고 다시 요청해 한도를 두 번 쓰므로, 항상 제한 시간보다 길게 둡니다.
- 음성은 Gemini가 직접 출력한 MP3(128kbps, 1시간 약 58MB)로 저장합니다. 권장 모델은 `gemini-3.8-flash-lite-tts`이며, Opus와 `bit_rate` 지정은 지원하지 않습니다(400). `gemini-3.8-flash-tts`의 MP3 지원은 확인하지 않았습니다.
- 무료 티어 한도는 모델별로 따로 잡힙니다. 2026-10-15 기준 `gemini-3.8-flash-tts`는 하루 10회였습니다.
- 진행률은 cron이 구간을 저장할 때마다 갱신되며, 책 상세를 새로고침하면 반영됩니다.

## 재생과 청취 기록

- 리더는 `/api/books/audio-chunk`로 구간을 조회합니다. 아직 생성되지 않았거나 재시도 중인 구간이면 404와 안내 메시지를 보여주고 멈춥니다.
- 나뉜 구간은 모든 조각이 준비된 뒤 `parts`로 한 번에 받아 순서대로 이어 재생합니다. 청취 위치는 조각 길이를 이어 붙인 구간 내 시간으로 저장합니다.
- 재시도를 모두 소진한 구간·조각(정책 차단 등)은 원문(`fallbackText`)을 받아 기기 음성(Web Speech, ko-KR)으로 문장 단위로 읽고 다음 AI 음성 구간으로 이어갑니다. 한도를 쓰지 않으며, 청취 위치와 챕터 완료도 저장합니다. 나중에 "생성 다시 시작"으로 AI 음성이 만들어지면 그 음성으로 바뀝니다.
- 다음 구간을 미리 받고, 미리 받지 못했으면 넘어갈 때 한 번 더 조회합니다. 그사이 생성이 끝났으면 이어서 재생합니다.
- 파일은 보호 파일입니다. 다운로드 경로에서 매번 원본 EPUB의 서재 접근 권한을 확인합니다.
- 브라우저에는 최근 16개 구간을 다운로드 캐시로 보관합니다.
- 사용자·EPUB·낭독 설정·챕터별로 구간, 구간 내 시간, 완료 상태를 DB에 저장하므로 다른 기기에서도 이어 듣습니다.
- 재생 중 15초 간격으로, 재생 시작·일시 정지·정지·페이지 종료 시에도 저장합니다. 저장 실패 시 브라우저에 임시 보관 후 다음 이어 듣기 전에 다시 전송합니다.
- **읽던 위치부터**는 리더 화면 첫 문단(공백 제외 40자 이상)이 들어 있는 구간 처음부터 재생합니다. 정밀도는 구간 단위(최대 약 7분 앞)이며, 찾지 못하면 챕터 처음부터 재생하고 안내합니다.
- 챕터를 다 들으면 구간이 있는 다음 챕터로 자동으로 넘어갑니다(목차·표지처럼 본문 없는 항목은 건너뜀). 마지막 챕터에서 멈춥니다.
- 완료한 챕터에서 재생을 누르면(이어 듣기) 다음 챕터 처음부터 재생합니다.
- 재생 전에는 이어 듣기 버튼 하나와 이어질 위치(챕터·챕터 내 시간)만 보여주고, 읽던 위치부터·현재 챕터 처음부터는 "다른 위치에서 시작"에 접어 둡니다. 재생을 시작하면 재생 바와 조작 버튼으로 바뀌며, 상태 문구는 오류·기기 음성 대체·동기화 대기 때만 표시합니다.
- 브라우저 기본 플레이어 대신 챕터 단위 재생 바를 씁니다. 챕터의 구간·조각 길이를 이어 붙여 `12:30 / 45:10`처럼 표시하고, 바를 끌거나 15초 앞뒤 이동을 하면 해당 구간·조각의 시간으로 이동합니다. 아직 음성이 없는 구간과 기기 음성 조각은 글자 수(초당 약 6.8자)로 길이를 추정하며, 챕터 처음·끝을 넘어 이동하지 않습니다.
- 재생 중에 읽어주기 패널을 닫으면 화면 아래(뒤로가기·메뉴 버튼 왼쪽)에 미니 플레이어가 나타납니다. 재생/일시 정지 버튼과 챕터명·재생 시간을 보여주고, 챕터명을 누르면 패널을 다시 엽니다. 정지하면 사라집니다.
- **듣는 곳으로 이동**은 재생을 멈추지 않고 패널을 닫은 뒤, 리더를 지금 읽는 문장으로 옮깁니다. 조각 안의 재생 시간 비율로 원문 위치를 추정해 그 문장 처음을 챕터에서 찾고(앞 24·14·8자 순), 찾지 못하면 챕터 처음을 엽니다.
- 이전·다음 챕터 버튼은 음성 구간이 있는 이전·다음 챕터의 처음부터 재생합니다(목차·표지처럼 본문 없는 항목은 건너뜀). 떠나는 챕터의 위치는 저장합니다.
- 잠금 화면·알림의 재생/일시 정지/15초 앞뒤 이동/탐색/이전·다음 트랙은 Media Session으로 같은 챕터 재생 바를 조작하며, 챕터 이름과 책 제목을 표시합니다.
- 다른 탭의 늦은 일반 저장은 완료 기록을 취소하지 않습니다. 명시적으로 처음부터 재생하면 완료 상태를 해제합니다.
- 독서 위치·독서 시간과 청취 기록은 별도로 관리합니다.

## 현재 범위
